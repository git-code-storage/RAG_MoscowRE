# 🏢 RAG_MoscowRE

Проект по исследованию и применению технологий **Retrieval-Augmented Generation (RAG)** на примере данных о новостройках города Москвы. В проекте используются языковые модели семейства **GigaChat** для интеллектуального поиска и генерации ответов на основе структурированных и неструктурированных данных.

## 📝 Описание
Проект демонстрирует различные подходы к построению RAG-систем: от базового векторного поиска до продвинутых техник вроде гибридного поиска и расширения контекста (Context Expansion). Основная цель — оценка качества ответов модели на контрольном наборе вопросов о московских новостройках.

> ⚠️ **Важно:** Для работы проекта необходим действительный API-ключ GigaChat.

---

## 🛠 Реализованные RAG-техники
1. **Базовая (с фильтрацией)** — векторный поиск с извлечением фильтров из запроса пользователя для уточнения результатов.
2. **Гибридная** — комбинация векторного поиска и полнотекстового поиска по ключевым словам для повышения релевантности.
3. **Базовая без фильтров** — классический векторный поиск без дополнительного структурированного фильтрования.
4. **Расширение контекста (Context Expansion)** — использование иерархии чанков: поиск выполняется по маленьким фрагментам (child), а в контекст модели передаются соответствующие им большие фрагменты (parent) для сохранения полноты информации.

## ⚙️ Требования и установка

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/RAG_MoscowRE.git
cd RAG_MoscowRE
```
### 2. Настройка окружения
Рекомендуется использовать виртуальное окружение Python (3.9+):
```bash
# Создание виртуального окружения
python -m venv venv

# Активация (Windows)
venv\Scripts\activate
# Активация (macOS/Linux)
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```
### 3. Настройка переменных окружения
Создайте в корневой папке проекта файл .env и добавьте в него ваш API-ключ GigaChat:

```env
GIGACHAT_AK=ваш_ключ_доступа_gigachat
```

### 4. Создание базы данных
Выполните один из ноутбуков для инициализации векторной базы данных (в зависимости от выбранной техники):
* notebooks/db_creation_with_meta.ipynb — для базовой техники с фильтрами и гибридного поиска. 
* notebooks/db_creation_without_meta.ipynb — для базовой техники без фильтров.


## ▶️ Запуск пайплайнов
Проект предоставляет как скрипты для автоматизированного запуска, так и Jupyter-ноутбуки для пошагового изучения.

| Техника | Скрипт для запуска | Ноутбук для изучения |
|---|---|---|
| Базовая и гибридная | `python run_pipelines.py` | `notebooks/base_pipeline.ipynb`, `notebooks/hybrid_pipeline.ipynb` |
| Базовая без фильтров | `python without_filters_pipeline.py` | `notebooks/base_pipeline.ipynb` (адаптировать) |
| Расширение контекста | `python ce_pipeline.py` | — |
| Итоговый лучший пайплайн | — | `notebooks/final_pipeline.ipynb` |
